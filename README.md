# Rust

> 🦀 Rust 个人项目合集
> 🤖 AI 辅助开发 · 🧪 实验性项目 · 🛠️ 各种小玩具

这里是我的 **Rust 项目集合**。

主要用于存放一些个人开发、实验以及各种临时起意的小项目。

大部分项目由 **AI 辅助完成**，包括代码生成、重构、调试、优化以及功能扩展。

所以这里的代码可能：

* 能跑
* 好用
* 偶尔抽风
* 偶尔需要人工解释一下为什么这样写
* 但至少能解决实际问题 😄

## 📦 项目

仓库中的项目以独立目录形式存在，每个项目通常可以单独编译、运行和部署。

内容主要涉及：

* 🚀 网络工具
* 📡 流媒体 / IPTV
* 🌐 Web 服务
* 🧰 Linux 工具
* ⚙️ VPS / 服务端脚本
* 🦀 Rust 实验项目
* 🤖 AI 辅助开发的各种小工具

## 🤖 AI Powered

这个仓库的一个特点是：

**代码主要由 AI 辅助完成。**

开发方式大致是：

```text
需求
 ↓
AI 生成
 ↓
运行测试
 ↓
发现问题
 ↓
AI 修复
 ↓
继续测试
 ↓
能用就算成功
```

因此这里更像是一个 **AI + Rust 的个人实验场**，而不是传统意义上的工程项目。

## ⚠️ 说明

这里的项目主要服务于个人使用和实验。

部分项目可能存在：

* 文档不完整
* 代码结构不够优雅

**没错，它可能就是 AI 写的。**

因为 Rust：

> 快、稳、能编译，
> 而且报错的时候非常诚实。

至于为什么不用其他语言？

**因为 AI 写 Rust 挺有意思。**
